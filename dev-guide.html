Stuntify Development Guide

Quick Access URLs

  • Development Server (Webpack) - http://localhost:3000
  • Flask API Server - http://localhost:5000

Troubleshooting ERR_CONNECTION_REFUSED

If you're seeing ERR_CONNECTION_REFUSED when accessing the application:

  1. Make sure both servers are running (check for two command prompt windows)
  2. Check that ports 3000 and 5000 are not already in use by other applications
  3. Run the troubleshooter script: troubleshoot.bat or npm run troubleshoot

Development Workflow

  1. Start both servers using: start-dev.bat or npm run start:windows
  2. Make changes to your code
  3. Webpack will automatically rebuild and refresh the browser
  4. View the application at http://localhost:3000

Development Tools

  • Flask Server: Handles Python backend logic, ML models, and API endpoints
  • Webpack Dev Server: Bundles JavaScript and CSS, provides hot reloading
  • Troubleshooter: Diagnoses common issues with the development environment

Common Commands

npm run build         # Build for production
npm run dev           # Build and watch for changes
npm run serve         # Start webpack-dev-server
npm run start:flask   # Start Flask server only
npm run start:dev     # Start both servers (Unix/Mac)
npm run start:windows # Start both servers (Windows)
npm run troubleshoot  # Run diagnostic tool
